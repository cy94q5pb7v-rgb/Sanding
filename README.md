# Arsenal FC · Fan Zone

Фанатское веб-приложение про лондонский «Арсенал». Сделано в клубных цветах (красный/золотой/тёмный фон), без зависимостей — чистый HTML + CSS + JS.

## Что внутри

- **Главная** — герой с девизом клуба *Victoria Concordia Crescit* и быстрой информацией (стадион, тренер, капитан)
- **Лайв-полоса статистики** с анимированными счётчиками (139 лет, 13 чемпионств, 14 кубков Англии, 49 матчей без поражений, 60 704 — вместимость Emirates)
- **Состав** — карточки игроков с фильтром по позициям (вратари / защитники / полузащитники / нападающие), номера, флаги, статистика матчей/голов/передач
- **Статистика сезона** 2024/25 — таблица, голы, оборона, владение, ЛЧ + топ-бомбардиры
- **Матчи** — предстоящие игры и результаты (вкладки)
- **Трофейная комната** — все основные титулы + отдельный блок про **The Invincibles** (2003/04)
- **Хронология** клуба от основания 1886 до наших дней
- **Футер** с песнями фанатов и финальным COYG

## Запуск

Просто откройте `index.html` в браузере. Никакой сборки и npm не требуется.

```bash
# или поднимите любой статический сервер
python3 -m http.server 8000
# затем http://localhost:8000
```

## Файлы

- `index.html` — разметка и контент
- `styles.css` — все стили, адаптивная вёрстка
- `app.js` — данные о составе/матчах/бомбардирах, рендер, анимации
